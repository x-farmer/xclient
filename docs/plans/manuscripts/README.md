# Plan Manuscripts

Store active implementation-plan drafts in this directory. Use:

`YYYYMMDD-<short-topic>.md`

Update an existing manuscript for the same topic instead of creating a
duplicate. Do not read unrelated manuscripts during ordinary development; they
are working context, not normative standards.

When consolidating manuscripts, preserve confirmed decisions, constraints,
architecture, implementation boundaries, open questions, and future work.
Resolve conflicts in favor of the newer or more explicit decision and call out
anything that remains unresolved. Write the consolidated long-term plan to the
parent `docs/plans/` directory and do not delete source manuscripts unless the
user explicitly requests deletion.
